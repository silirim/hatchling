# Re-read an unchanged file

The agent read a file it had already read in this chat, and the file had not changed. Cachito shows it as a note: it costs the pet nothing.

## If you want to step in

1. Press **fix** in the band, then Enter: it asks the agent to use what is already in context.
2. In your prompts, point to the place: "in `src/app.js` around line 120".

The note goes away after two turns. After a compaction a second read is not a re-read.
